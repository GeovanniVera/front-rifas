# i18n

Internacionalización con i18next.

## Archivos

| Archivo | Función |
|---------|---------|
| `src/lib/i18n/config.ts` | Inicializa i18next con React |
| `src/lib/i18n/errors.ts` | Mapea `ApiErrorCode` a claves de traducción |
| `src/lib/i18n/locales/es.json` | Traducciones al español (~130 keys) |
| `src/lib/i18n/locales/en.json` | Traducciones al inglés |

## Configuración

```typescript
// src/lib/i18n/config.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import es from './locales/es.json';
import en from './locales/en.json';

function getSavedLang(): string {
  try {
    return localStorage.getItem('i18n_lang') || 'es';
  } catch {
    return 'es';
  }
}

i18n.use(initReactI18next).init({
  resources: { es: { translation: es }, en: { translation: en } },
  lng: getSavedLang(),
  fallbackLng: 'es',
  interpolation: { escapeValue: false },
});

i18n.on('languageChanged', (lng) => {
  try { localStorage.setItem('i18n_lang', lng); } catch {}
});

export default i18n;
```

## Error Mapping

```typescript
// src/lib/i18n/errors.ts
import { ApiErrorCode } from '../api/types/api-response';

const ERROR_MAP: Record<ApiErrorCode, string> = {
  UNAUTHORIZED: 'errors.unauthorized',
  FORBIDDEN: 'errors.forbidden',
  NOT_FOUND: 'errors.notFound',
  VALIDATION_ERROR: 'errors.validation',
  CONFLICT: 'errors.conflict',
  NETWORK_ERROR: 'errors.network',
  TIMEOUT: 'errors.timeout',
  SERVER_ERROR: 'errors.server',
  UNKNOWN: 'errors.unknown',
  RATE_LIMITED: 'errors.rateLimited',
};

export function getErrorMessage(errorCode: ApiErrorCode): string {
  return ERROR_MAP[errorCode] || 'errors.unknown';
}

export function getErrorKey(errorCode: ApiErrorCode): string {
  return ERROR_MAP[errorCode] || 'errors.unknown';
}
```

## Uso

```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('auth.login.title')}</h1>
      <p>{t('auth.login.subtitle')}</p>
      <button>{t('auth.login.submit')}</button>
    </div>
  );
}
```

## Persistencia

El idioma se guarda en `localStorage['i18n_lang']` y sobrevive recarga.

## Fallback Chain

Si falta la key, devuelve `errors.unknown`.

## Idiomas Soportados

| Código | Idioma |
|--------|--------|
| `es` | Español (default) |
| `en` | Inglés |

## Nota

Algunos strings en `pages/` están hardcodeados en español (déudito técnico para i18n).
